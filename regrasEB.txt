Comandos de Resposta:

Agora irei prosseguir o recrutamento explicando os comandos de resposta, sendo eles:

ESQUERDA VOLVER ! DIREI TA VOLVER ! RETAGUARDA ! CONTROL FACE ! CENTRAL FACE !

ESQUERDA VOLVER: Você irá virar para sua esquerda.

DIREI TA VOLVER: Você irá virar para sua direi ta.

RETAGUARDA: Você irá virar para o lado oposto (o lado de trás) do atual.

CENTRAL FACE: Você irá virar para o posto inicial, no caso onde o instrutor se encontra.

CONTROL FACE: Você irá seguir o instrutor, usando a camêra.

Comandos de Formação:

Agora irei explicar comandos que são utilizados para fazerem formações:

Formação: É o comando no qual os soldados devem ficar em cima de um dos quadrados, ficando em posição de ombro á ombro quando dado o comando.

Fila única: É o comando no qual os soldados deve fazer uma fila atrás do Oficial organizadamente, sem ficar grudado nos outros militares quando dado o comando: Fila única! Comandos de Marcha:

Atualmente temos alguns comandos de marcha, sendo eles:

PREPARAR PARA MARCHAR !

MARCHEM/MARCHANDO !

e AUTO !

O comando PREPARAR PARA MARCHAR serve para informar aos soldados para se prepararem, para a marcha.

O comando MARCHEM é um comando no qual manda os militares marcharem atrás do instrutor.

O comando AUTO serve para informar aos soldados que é para pararem de marchar.

Comandos de Pelotão de Tiro:

Aqui temos comandos aos quais são ordenados com a utilização da arma, sendo eles:

PREPARAR ! (Pegue a arma)

APONTAR ! (Mire com a arma no alvo indicado)

FOGO ! (Apenas atire uma única vez, ou seja, um tiro)

FOGO LIVRE ! (Atire até descarregar o pente e não recarregue a arma)

CESSAR FOGO ! (Pare de atirar)

RECARREGAR ! (Recarregue a arma apertando R)

DESARMAR ! (Retire a arma da mão)

Comandos Falsos:

No Exército existem os comandos falsos, que fazem parte de todos os comandos do Exército Brasileiro, sendo eles: Comandos de resposta, comandos de marcha e todos os outros comandos em geral.

Para detectar se um comando falso é necessário ler a escrita e ver se está correta, se ela estiver incorreta é um comando falso, mesmo faltando algum caractere (letras,números,simbolos,etc...)

Após explicar isto dê exemplos de comandos falsos. Pergunte aos civis: Alguma dúvida?

Faça alguns JJ's com prática.
